  4. Attend the personal interview round.

Web Technology Definitions

HTML (HyperText Markup Language)
The standard markup language used to create the basic structure and layout of webpages.

CSS (Cascading Style Sheets)
A stylesheet language used to describe the presentation, design, colors, and layout of a webpage.

JavaScript
A dynamic programming language used to add interactive features, logic, and complex functionality to webpages.
